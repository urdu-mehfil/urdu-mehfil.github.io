تینوں دیاں ہنجواں دا بھاڑا
نی پیڑاں دا پراگا بھن دے
بھٹھی والیے!
بھٹھی والیے چنبے دیے ڈالیے
نی دکھاں دا پراگا بھن دے
بھٹھی والیے!
ہوگیا کویلا مینوں
ڈھل گئیاں چھاواں نی
بیلیاں چو مڑ آئیاں
مجھیاں تے گاواں نی
پایا چڑیاں نے چیک چہاڑا
نی پٹراں دا پراگا بھن دے
بھٹھی والیے!
تینوں دیاں ہنجواں دا بھاڑا
نی دکھاں دا پراگا بھن دے
بھٹھی والیے!
چھیتی چھیتی کریں
میں تے جانا بڑی دورنی
جتھے میرے ہانیاں دا
ٹرگیا پورنی
اوس پنڈ دا سنیندا اے راہ ماڑا
نی پیڑاں دا پراگا بھن دے
بھٹھی والیے!
تینوں دیاں ہنجواں دا بھاڑانی
بھٹھی والیے!
میری واری پتیاں دی
پنڈ سلھی ہوگئی
مٹی دی کڑاہی تیری
کاہنوں پلی ہوگئی
تیرے سیک نوں کیہ وجیا دگاڑا
نی پیڑاں دا پراگا بھن دے
بھٹھی والیے!
تینوں دیاں ہنجواں دا بھاڑا
نی دکھاں دا پراگا بھن دے
بھٹھی والیے!
لپ کو اے چنگ میری
مینوں پہلاں ٹورنی
کچے کچے رکھ نہ نی
روڑ تھوڑے ہورنی
کراں منتاں مکا دے نی پاڑا
نی پیڑاں دا پراگا بھن دے
بھٹھی والیے!
تینوں دیاں ہنجواں دا بھاڑا
نی دکھاں دا پراگا بھن دے
بھٹھی والیے!
سوں گئیاں ہوواں رو رو
کرو رلاپ نی!
جنج ساہواں دی دا رس گیا لاڑا
نی پیڑاں دا پراگا بھن دے
بھٹھی والیے!
