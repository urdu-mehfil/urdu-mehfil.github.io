محترم سخنور جی
کلام بابا بلھے شاہ
مختصر الفاظ میں اک پوری کتاب
بابا بلھے شاہ کی یہ خود کلامی جس میں وہ اپنے آپ کو تلقین کر رہے ہیں کہ
عابد وہی جو شب بیدار ہو ( قم اللیل الا قلیلا ) اور اپنے نفس کو سمجھا رہے کہ
دیکھ یہ کتا جو کہ نجس عین ہے ۔ اپنے مالک کا کتنا وفادار ہے ۔ اس کی جھڑکیاں مار سہہ کر بھی رات کو جاگ کر اس کے مال ملکیت کی رکھوالی کرتا ہے ۔ کیا ملتا ہے اسے مالک سے وفاداری کا ۔ تین وقت کا راتب اور پیار ۔۔
تو اے میرے نفس تو کس قدر گمراہ ہو کر لذات نفسانی میں الجھ گیا ہے کہ تجھے اس مالک کا شکر ادا کرنا بھی گراں گزرتا ہے ۔ یاد کر وہ کلمہ طیبہ کہ ( کیا میں اپنے رب کا شکر گزار بندہ نہ بنوں )اے میرے نفس اگر میں اپنے قول و فعل و عمل میں اپنے رب ( مالک ) کی شکر گذاری نہ کروں تو یہ کتا تجھ سے اچھا ہے کہ اس کا عمل مالک سے شکرگذاری کا ہے ۔
(کیا میں اس کلام کو سمجھ پایا ہوں ؟ )
