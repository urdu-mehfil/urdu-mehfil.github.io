جہڑے دن دا
سجن ورگا پِنڈ چھڈیا اے
بھولے بھالے مُکھ نئیں ویکھے
وِیراں ورگے رُکھ نئیں ویکھے
شہر چ بھاویں دُکھ نئیں ویکھے
اوہو جئے پر سُکھ نئیں ویکھے
جہڑے دن دا
ماہیے ورگا پِنڈ چھڈیا اے
ہاں اچ رَلدی ہاں نئیں ویکھی
سانجھاں نئیں سن تاں نئیں ویکھی
اک وی چج دی تھاں نئیں ویکھی
ماواں ورگی چھاں نئیں ویکھی
جہڑے دن دا
ڈھولے ورگا پِنڈ چھڈیا اے
سَچے سُچے پیار نئیں ویکھے
یاراں دے میں یار نئیں ویکھے
لونگاں دے لشکار نئیں ویکھے
او کونجاں دے ڈار نئیں ویکھے
جہڑے دن دا
ہیرے ورگا پِنڈ چھڈیا اے
شہد جئے نئیں گنے ویکھے
چُوری دے نئیں چھنے ویکھے
نا او وٹاں بَنے ویکھے
نا او بُوہے چنے ویکھے
جہڑے دن دا
تیرے ورگا پِنڈ چھڈیا اے
بُہتے کتھے چند نئیں ویکھے
سجناں دے کوئی پندھ نئیں ویکھے
دُدھ جئے چِٹے دند نئیں ویکھے
او نظماں دے بند نئیں ویکھے
جہڑے دن دا
شعراں ورگا پِنڈ چھڈیا اے
نیڑے تے میں دور نئیں دیکھے
اکھراں وچ سُرور نئیں ویکھے
مصرعے نُورونور نئیں ویکھے
غزلاں دے میں پُور نئیں ویکھے
۔۔۔۔
