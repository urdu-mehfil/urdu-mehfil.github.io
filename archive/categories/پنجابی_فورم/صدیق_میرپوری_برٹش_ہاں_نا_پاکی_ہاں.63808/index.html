صدیق میرپوری : برٹش ہاں نا پاکی ہاں

سید زبیر — مئی 13، 2013 4:39 شام
ہیلی فیکس یوکے توں​
صدیق میرپوری، دا کلام​
​
برٹش ہاں نا پاکی ہاں​
اک عاجز بندہ خاکی ہاں​
میں وچ ولائیت رہندہ ہاں​
دُکھ درد ہزاراں سہندہ ہاں​
نہ ساڑی ہاں نہ لہنگا ہاں​
اک لیراں لَتھی ٹاکی ہاں​
برٹش ہاں نہ پاکی ہاں​
​
میں پاؤنڈ کماون آیا ساں​
یا نسل گماون آیا ساں​
بگڑی نوں بناون آیا ساں​
ہُن بن گیا ہجر فراقی ہاں​
برٹش ہاں نا پاکی ہاں​
​
میں وطن پیارا چھوڑ دتا​
کی کھٹیا کی میں روہڑ دتا​
دل میرا دنیا توڑ دتا​
شرابی ہاں نہ ساقی ہاں​
برٹش ہاں نہ پاکی ہاں​
​
مینوں اپنے وی گل لاؤندے نیئں​
نالے گورے وی کول بٹھاؤندے نیئں​
دکھ جھلے میں تھوں جاؤندے نیئں​
میں آخر اک بلیکی ہاں​
برٹش ہاں نہ پاکی ہاں​
​
کوئی بگڑی نیئں بنا سکدا​
نسل اپنی نیئں بچا سکدا​
دکھ درد نیئں چھپا سکدا​
نہ لاٹھی ہاں نہ ہاکی ہاں​
برٹش ہاں نہ پاکی ہاں​
​
جد پاکستاں میں جاندا ہاں​
اُوہدوں ویزہ وی لگواندا ہاں​
نالے دھکے وکھرے کھاندا ہاں​
جیویں پاکی بس اتفاقی ہاں​
برٹش ہاں نہ پاکی ہاں​
​
پاسپورت تے دو دو رکھدا ہاں​
ائیرپورٹ تے فیر وی پھسدا ہاں​
میں اپنے آپ تے ہسدا ہاں​
کیوں زلت لئی میں باقی ہاں​
برٹش ہاں نہ پاکی ہاں​
ایتھوں جا کے اوتھے رَلدا نئیں​
جیویں کھوٹا سکہ چلدا نئیں​
کوئی جیب کٹن توں ٹلدا نئیں​
نہ ہون جیہا میں باقی ہاں​
برٹش ہاں نہ پاکی ہاں​
​
میں شاعر صدیق دیوانہ ہاں​
گھر اپنے وچ بیگانہ ہاں​
گل سچی آکھ سنانا ہاں​
نہ کردا کوئی چلاکی ہاں​
برٹش ہاں نہ پاکی ہاں​
اک عاجز بندہ خاکی ہاں​
​
