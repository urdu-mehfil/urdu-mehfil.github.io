محبّت کسی سے نبھا کر تو دیکھو

محبّت کسی سے نبھا کر تو دیکھو
کبھی روگ دل کو لگا کر تو دیکھو
--------
تمہیں زندگی تب سہانی لگے گے
محبّت کی نگری میں آ کر تو دیکھو
--------
تمہیں شوخیاں بھول جاتی پڑیں گی
محبّت کو دل میں بسا کر تو دیکھو
----------
ستائے گی تم کو مری یاد ہر پل
کبھی مجھ سے پہلو بچا کر تو دیکھو
--------
تمہیں پیار کے گیت اچھے لگیں گے
محبّت کے نغموں کو گا کر تو دیکھو
----------
یہ وعدہ ہے میرا محبّت کروں گا
کبھی مجھ کو اپنا بنا کر تو دیکھو
--------
نشے میں رہیں گی تمہاری نگاہیں
محبّت کے سپنے سجا کر تو دیکھو
---------
کرو گے محبّت ، محبّت ملے گی
محّلے میں چاہت کے آ کر تو دیکھو
---------
تمہیں پیار کرنا سکھا دوں اک دن
مسلسل مرے پاس آ کر تو دیکھو
----------
تمہیں خواب ارشد کے آنے لگیں گے
کبھی اس سے نظریں ملا کر تو دیکھو
----------
