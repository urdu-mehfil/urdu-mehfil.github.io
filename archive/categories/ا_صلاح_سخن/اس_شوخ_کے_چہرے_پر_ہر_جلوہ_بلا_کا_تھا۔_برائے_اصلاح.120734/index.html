# رخسار پہ رہ رہ کر، کیا تھا کہ مچلتا تھا
مہتاب کی ضو اُس میں، خورشید کی حدت تھی
میں اور بتاؤں کیا، اُس رخ پہ عیاں کیا تھا
// مہتاب سی اور خورشید سی بہتر رہے گا میرا خیال ہے
عیاں اور 'میں اور بتاؤں کیا' مصرع میں خرابی پیدا کر رہے ہیں، 'رخ سے عیاں' شاید ٹھیک رہے مگر 'اور بتاؤں کیا' کا کوئی متبادل ڈھونڈنا ہو گا
اُس شعلہ نظر نے تھی، جس جس پہ نگہ ڈالی
نظروں کی حرارت سے ہر جسم پگھلتا تھا
// نگہ ڈالی کی جگہ بھی نظر ڈالی کا ہی محل ہے شاید، دوسرا مصرع مکمل تبدیل کرنے کی ضرورت ہے، ربط بھی نہیں بن رہا اور 'نظروں' کی ضرورت نہیں رہتی جب پہلے مصرع میں یہی بات کی گئی ہے
وہ میر کے مصرعوں کی تمثیل تھی گویا اک
ہر لفظ مناسب تھا، لہجہ بھی شگفتہ تھا
// مصرعوں میرا خیال ہے کہ وزن میں نہیں آئے گا، 'عوں' 'روں' مجھے نہیں لگتا کہ کیا جا سکتا ہے، اس کی جگہ 'شعروں' لا سکتے ہیں
دوسرا مصرع اگر یوں ہو تو میرا خیال ہے ربط بھی بنے گا اور واضح بھی ہو جائے گا کہ کس کا
// ہر لفظ حسیں جس کا، لہجہ
جو لفظ اُس افسوں گر کے ہونٹ سے نکلا وہ
کیا کیا نہ معانی کے، تہ کھولتا جاتا تھا
// مفعول مفاعیلن دو بار والی یہ بحر دو حصوں میں منقسم ہوتی ہے، ہر حصہ میں بات مکمل ہونا چاہیے۔
یوں بہتر ہوتا ہے
جو لفظ فسوں گر کے، ہونٹوں سے تھا نکلا وہ
البتہ دوسرا مصرع درست نہیں لگ رہا، 'تہیں' کھولتے جانے کا محل لگتا ہے
خالی نہ گیا کوئی، خالی نہ گیا کوئی
اُس آنکھ کی ترکش سے، جو تیر بھی نکلا تھا
// پہلا مصرع بدلنے کی ضرورت ہے، خالی جانا بھی نشانے پر نہ لگنے کے معنوں میں میرا نہیں خیال کہ درست ہے، اس پر دو بار کہا جانا بھی بھلا نہیں لگ رہا
یوں اس کے لبِ لعلیں رونق تھے گلستاں کی
ہر پھول پہ اُن کا ہی، بس رنگ جھلکتا تھا
// یہ ٹھیک لگ رہا ہے مجھے
ہر شخص کو ہوتا تھا، راتوں میں گماں دن کا
جب رات گئے چھت پر وہ شخص ٹہلتا تھا
// یہ بھی
پھر ایک وہ دن آیا، کہرام تھا گلیوں میں
سامانِ سفر جس دن، اُس شخص نے باندھا تھا
// اس کا تعلق پچھلے شعر کے ساتھ لگتا ہے، اگر ایسا ہی ہے تو قطع کی نشاندہی کی جانی چاہیے
کوئی خرابی البتہ نظر نہیں آ رہی اس میں مجھے
خورشید ہوا مدھم، مہتاب ہوا بے نور
برپا تھی قیامت اک، اُس شخص کا جانا تھا
// برپا تھی قیامت یا
مصرع اولی میں بھی گرامر کی کوئی گڑبڑ معلوم ہو رہی ہے، دونوں ٹکڑوں میں شاید 'تھا' ہی کا استعمال ہونا چاہیے تھا
//خورشید بھی تھا مدھم، مہتاب بھی تھا بے نور
اب اپنا نصیبہ ہے، قسمت کی سیاہی ہے
اک شخص کے ہونے سے، کیا کیا نہ اجالا تھا
// اولی دوبارہ کہنے کی ضرورت ہے، نصیبہ مس فٹ لگ رہا ہے
بہت معذرت کہ ٹیگ نہ ہونے کے باوجود میں نے اپنی رائے پیش کی، در اصل یونہی لیٹا ہوا تھا تو آپ کی اس غزل پر لکھنے بیٹھ گیا
